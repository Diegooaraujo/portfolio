# Diego Araújo - Portfolio

## Descrição

Este repositório contém o código-fonte do portfólio de **Diego Araújo**, um desenvolvedor focado em aprender e aplicar tecnologias modernas para criar soluções eficientes.

## Estrutura do Projeto

- **index.html**: Página principal do portfólio, apresentando uma visão geral e links para outras seções.
- **cursos.html**: Página dedicada aos cursos realizados pelo desenvolvedor.
- **projetos.html**: Página que exibe os projetos desenvolvidos.
- **css/**: Diretório contendo arquivos de estilos CSS.
- **icones/**: Diretório contendo ícones utilizados no site.
- **img/**: Diretório contendo imagens utilizadas no site.
- **scripts/**: Diretório contendo scripts JavaScript utilizados no site.

## Páginas

- **Home**: Introdução e apresentação do desenvolvedor.
- **Projetos**: Listagem e descrição dos projetos desenvolvidos.
- **Cursos**: Listagem e descrição dos cursos realizados.
- **Contato**: Informações de contato e redes sociais.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
